# FIELDCRAFT

JavaScript と Three.js で作った、一人称視点の小さなブロックサンドボックスです。64 × 64 ブロックの草原を歩き、木や地面から集めた素材で建築できます。最初の持ち物は空で、自分で採掘したアイテムだけを使います。右上には実測した FPS を表示します。

必要なツールの用途・料金、Windows / Mac のインストール、GitHub の基本操作は [初心者向け開発ガイド](docs/DEVELOPMENT.md) を参照してください。開発方針は [AGENTS.md](AGENTS.md) に保存しています。

自作コードには日本語の説明コメントを付けています。[コードの読み方・設定ファイルの説明](docs/CODE_GUIDE.md) に、読む順番と、コメントを直接書けない JSON の各項目もまとめています。

## 起動

Node.js 24 LTS を推奨します（対応下限は 22.12、この環境では `.nvmrc` と同じ 24.19.0）。以下はクラウド環境のパスです。自分の PC では、展開したプロジェクトフォルダーで実行してください。

```sh
cd /workspace/tst-game
npm ci
npm run dev
```

ブラウザで開き、「世界に入る」をクリックすると始まります。マウスとキーボードを使える PC ブラウザと WebGL が必要です。マウスの捕捉が必要なため、制限のある埋め込み画面では直接ブラウザで開いてください。

### サーバーなしで開く

```sh
npm run export
```

`artifacts/fieldcraft.html` に JavaScript・CSS・画像をすべて含む 1 ファイル版を生成します。このファイルを PC にダウンロードし、Chrome または Edge で開くと遊べます。Node.js のインストールやサーバー起動は、完成した HTML を遊ぶ側には不要です。

## 操作

| 入力 | 操作 |
| --- | --- |
| W / A / S / D | 前後左右に移動 |
| マウス | 見回す |
| Space | ジャンプ（押し直すと次のジャンプ） |
| 左 Shift + 移動 | 走る |
| 左クリック | 照準のブロックを壊し、同じ素材を1個入手 |
| 右クリック | 選択した素材を1個使って、照準の面に設置 |
| 1 ～ 6、マウスホイール | ホットバーのスロットを選ぶ |
| Tab | インベントリを開く・閉じる |
| Esc | 一時停止・感度とキー設定（インベントリ中も設定へ移る） |
| R | はじまりの場所へ戻る |

操作できるブロックは 6m 以内です。自分と重なる場所には設置できません。足元・壁・天井との衝突判定があり、地面を掘ると下の層へ降ります。草原の外などに落ちると安全な場所に戻ります。

上のキーは初期設定です。プレイ中に **Esc** を押すと「マウス感度」「キー設定」のタブを選べます。感度は **10〜300%**（標準 100%）。キー設定は変更したい操作のボタンを押し、新しいキーを押すと反映されます。同じキーを別の操作へ重複登録できません。入力待ち中の Esc は変更の取り消しになり、通常の Esc は一時停止用に固定です。それぞれのリセットボタンで標準設定へ戻せます。

感度とキー設定は同じブラウザに保存され、次回起動時にも使えます。保存が許可されなくても、その起動中は反映されます。ダウンロード版で保存場所やブラウザを変えた場合は、再設定が必要になることがあります。

**素材の集め方:** 所持数0個・空のホットバーで開始します。左クリックでブロックを壊すと、その素材を1個獲得し、空いているホットバーへ自動登録します。右クリックで設置に成功すると1個消費します。0個では設置できず、自分と重なる場所など設置に失敗したときは消費しません。

**インベントリの使い方:** Tab で所持数を確認できます。下のスロットを選び、入手済みの素材をクリックすると割り当てられます。未入手の素材は0個表示で選べません。同じ素材を複数スロットに登録しても在庫は共有され、個数は増えません。最後の1個を使うと、その素材のスロットは空になります。Tab または「ゲームにもどる」で再開します。メニュー中は移動・地形編集を停止します。

**FPS 表示:** 実際の描画フレームと経過時間を約 0.5 秒ごとに集計します。初回集計前は `-- FPS` と表示します。

ワールド、素材の所持数、ホットバーの並びはタブ内のメモリに保持します。一時停止では残りますが、再読み込みすると初期状態に戻り、所持数も0個からになります。感度・キー設定の保存とは別です。ワールドのセーブ、無限地形、マルチプレイはありません。

## 検証

```sh
npm test         # 地形生成、ブロック編集、照準、床・壁・天井、ジャンプなど
npm run build   # 配布用の dist/ を生成
```

別ターミナルで開発サーバーを起動した状態で、実際の Chromium 操作も検証できます。

```sh
# 初回のみ。クラウド環境では導入済みのシステム Chromium を使うため不要:
npm run test:browser:install
npm run test:browser
# システム Chromium のパスが違う場合:
CHROMIUM_PATH=/path/to/chromium npm run test:browser
```

システム Chromium がない Windows / Mac などでは、Playwright が導入した Chromium を自動で選びます。Playwright とテスト用ブラウザは無料です。

ブラウザテストは実際にマウスを捕捉し、移動・ジャンプ・ブロック破壊と設置・一時停止と再開を確認します。`artifacts/` に開始画面とプレイ画面の画像を保存します。初期 URL は `http://127.0.0.1:5173` で、`BASE_URL` で変更できます。

## ファイル

- `src/main.js`: 入力、ゲームループ、UI、ブロック編集
- `src/world.js`: 草原・木の生成、ボクセル管理、DDA レイキャスト
- `src/physics.js`: プレイヤーの重力・移動・AABB 衝突判定
- `src/settings.js`: マウス感度の設定・保存
- `src/keybindings.js`、`src/keybind-panel.js`: 操作キーの検証・保存・設定画面
- `src/inventory.js`: 素材の有限な所持数・消費・ホットバーの割り当て
- `src/block-actions.js`: 地形の採掘・設置と、アイテムの増減をまとめて管理
- `src/fps.js`: 実際の描画時刻から FPS を集計
- `src/render.js`: Three.js 描画、見えている面だけのメッシュ、手続き生成テクスチャ
- `src/style.css`: スタート画面、照準、ブロックパレット
- `src/settings.css`: 一時停止画面、マウス感度スライダー
- `src/game-ui.css`: FPS、インベントリ、キー設定の表示

画像テクスチャは起動時に生成するため、外部画像や CDN は不要です。
